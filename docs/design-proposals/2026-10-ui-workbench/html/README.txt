Quant Studio 四个设计技能 HTML Demo
制作日期：2026-10-11

打开方式
直接双击 index.html。它是自包含文件，内含四份可交互 Demo，不依赖同目录资源或网络。
也可以直接打开 01-impeccable.html、02-ui-ux-pro-max.html、03-taste-minimalist.html、04-anthropic-frontend-design.html。
对比页提供四版总览、左右对比、单版体验，及桌面/平板/手机视口。
在总览里页面按相同视口缩小；点击“放大比较”或“打开”再体验表单。

可以试的流程
1. 选择 A 股因子、期货期限结构或期权波动率。
2. 修改初始资金、手续费、日期或训练占比，点击“保存新版本”。
3. 查看版本记录，确认原版本仍保留。
4. 点击“模拟运行”，待完成后从最近运行打开报告。
5. 搜索任务、筛选状态、切换曲线区间、展开曲线数据表。
6. 点击预检中的“异常示例”，体验运行阻止与恢复路径。

数据边界
所有研究与净值都是合成样例。参数只用于演示方案保存和运行流程，不会计算真实收益。
没有调用量化工作台后端，没有修改正式量化仓库，没有部署新的研究功能。
方案版本保存在各 Demo 自己的浏览器 localStorage；浏览器不允许存储时降级到当前会话。
刷新后模拟运行记录重置为初始演示任务，保存的方案版本仍可在同一浏览器来源访问。

技能与方法
四版由同一模型在同一会话中分别遵循原始技能规则实现，复用数据与行为代码，视觉布局分别编写。
这不是四个隔离会话的盲测，不是技能自动生成器的固定输出，不据此给出技能能力排名。
Taste 使用同项目的 minimalist-ui 分支；默认 taste-skill v2 明确不针对仪表盘。
Impeccable 实际执行 context、concept-seed、craft-floor、detect；用户直接委托 Demo 设计，未增加交互式概念选型审批。
UI UX Pro Max 实际执行设计系统与图表检索，舍弃检索中不适合研究工具的营销页结构。
字体使用本机系统字体回退，无字体 CDN。不同操作系统可能有轻微字体差异。

随附文件
prompts.txt：共同任务和各版提示词。
design-decisions.txt：实际设计依据、技能分支与执行边界。
sources.json：原始仓库、固定版本或获取日期、本地技能摘要哈希。
checks.json：自动化交互与视口检查结果。
preview.png：四版总览截图。

全部页面在文件模式下验证：无外部网络请求、无 JavaScript 错误；检查 375/390/768/1024/1440px 的横向溢出，桌面及手机均验证保存与模拟运行。
