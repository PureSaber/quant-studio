共同任务
为 Quant Studio 量化研究工作台制作独立 HTML Demo，中文优先，面向需要长时间使用工具的个人研究者。用户当前目标是打通研究开发链路，不是推销策略收益。使用完全相同的虚构项目与合成净值数据，包含：研究方案参数、不可变版本、运行任务、数据预检、净值与基准对比。所有数据明确标为演示。
提供可操作的方案切换、参数编辑、版本保存、模拟运行、任务筛选、曲线区间切换和报告详情。手机和桌面均可使用。纯 HTML/CSS/JS，自包含、离线运行，无外部字体、无真实数据接口、无生产写入。保持内容与交互能力一致，视觉布局由各技能分别指导。不得只替换颜色。

A — Impeccable
应用 impeccable v4.5.2 的 Operate 模式。先明确任务顺序与区域，再落地新界面。用户已经委托你选择合适提示词并直接交付 Demo；这些是供比较的提案，不是上线审批。采用 code-led 实现。强调清楚的工作区边界、信息层级、可读性、桌面与手机行为，以及正在运行/错误/空状态。执行 context、concept-seed、craft-floor 和最终 detect。做一次批量视觉检查及必要修复。

B — UI UX Pro Max
应用 ui-ux-pro-max。先运行设计系统检索 financial analytics dashboard；若混入营销页框架，收窄为 research analytics dashboard 并核对返回结果。密度 8/10。仅采用适合研究工具的推荐；不要把 Contact Sales 或营销 Hero 搬进工作台。使用得到的蓝色数据、琥珀提示、Fira 系列字体角色建议（离线条件下使用本机字体回退），以仪表盘布局突出指标、曲线、数据预检和任务筛选。运行 chart 检索，选择匹配时间序列的折线图，提供非颜色区分与数据表。

C — Taste Skill / minimalist-ui
采用 Leonxlnx/taste-skill 项目的 minimalist-ui（skills/minimalist-skill），不是默认 v2 的 design-taste-frontend；默认 v2 原文排除了仪表盘。设计阅读：长期研究使用的安静文档式工作台。严格体现暖白、炭灰、低饱和状态色、大留白、衬线标题与清晰正文、扁平非阴影组件；无渐变。把研究方案作为主文档，结果作为图表与笔记区。功能与其他版本相同，保留可扫读性和手机交互。

D — Anthropic frontend-design
按原始 frontend-design 指引先做设计方案，再自检是否泛化。为量化研究者提供一个有独特身份的研究工作区，选择非营销型视觉表达。把最具领域特征的净值比较图作为工作焦点，用独立的方案检查器承载参数和预检。大胆仅用在一处：宽幅结果画布；其余保持安静、严谨。使用明确的颜色/字体/布局 token，避免霓虹金融终端、渐变大标题、同尺寸卡片堆砌。交付前用桌面与手机截图复核。

比较说明
四份由同一模型在当前会话中分别遵循上述技能规则实现。共用数据和行为代码以减少功能差异；布局与视觉分别编写。不是四次隔离模型会话，也不是技能自动生成器的确定性输出。提示词方向不同，因此这是一组设计探索，不是受控能力排名。
